# VideoQuick

**Видео меньше. Действий меньше.** Лёгкий нативный сервис для macOS: конвертация из Finder и простой редактор, когда нужно быстро обрезать или кадрировать ролик.

[**Скачать DMG для Apple Silicon**](https://github.com/volodyatoxic/videoquick-macos/releases/download/v0.1.0/VideoQuick-0.1.0-arm64.dmg) · [English](README.md)

macOS 14+ · Apple Silicon · Swift / SwiftUI / AppKit · MIT

> Предварительная версия: DMG подписан ad-hoc и пока не нотарифицирован Apple. macOS может заблокировать запуск. [Подробности установки](docs/INSTALL.md).


## Конвертация без большого приложения

В Finder выдели один или несколько MOV/MP4 → **Конвертировать → 1 / 3 / 5 / 10 / 20 Mbps**. Новые файлы добавляются в общую очередь. Одновременно сохраняется один ролик; копия появляется рядом с оригиналом, например `Forest_3mbps.mov`. Исходники и готовые файлы не перезаписываются.


Только полоски прогресса и отмена. До 15 файлов на странице, ширина по размеру исходника, ожидающие полоски пустые.

## Редактор — только необходимое

- Обрезка краёв, разрезание и удаление фрагментов.
- Кадрирование: auto, 1:1, 4:3, 16:9, 3:4, 9:16. Положение и зум общие для всего монтажа.
- Перемещение картинки мышью или двумя пальцами, зум жестом или колесом.
- Звук, полный сброс, undo/redo, шаг по кадрам, магнит к плейхеду.
- Сохранение с выбором битрейта и прогрессом прямо на таймлайне.

**Пробел** — play/pause; **⌘B** — разрезать; **Backspace** — удалить фрагмент под плейхедом; **⌘Z / ⇧⌘Z** — undo/redo. **← →** — кадр, с Shift — 10 кадров. **⌘+ / ⌘− / ⌘0** — масштаб таймлайна. Команды редактора работают независимо от раскладки.

## История с полезными цифрами


Битрейт, исходный и итоговый размер, процент экономии, измеренное время экспорта. Окно показывает последние 30 дней, все записи продолжают храниться. Двойной клик открывает исходник в редакторе. Превью остаются только в памяти.

## Установка

1. [Скачай DMG](https://github.com/volodyatoxic/videoquick-macos/releases/download/v0.1.0/VideoQuick-0.1.0-arm64.dmg).
2. Перетащи VideoQuick в «Программы» и открой установленную копию.
3. В меню **VideoQuick → Настроить меню Finder…** включи расширение **VideoQuick Finder**, если оно ещё не включено.
4. Нажми правой кнопкой на MOV/MP4 в Finder.

Поддерживаются H.264/HEVC SDR до 8 бит. Обычная конвертация сохраняет формат, кодек, разрешение, ориентацию, звук и поддерживаемые метаданные; сохранение из редактора отбрасывает исходные метаданные и служебные дорожки. HDR/10-bit/ProRes и неподдерживаемые структуры дорожек отклоняются явно. Если выбранный битрейт выше исходного, файл может увеличиться.

Без аккаунта, облака, аналитики, Electron и встроенного FFmpeg. [Сборка из исходников](docs/BUILDING.md) · [Поддержка форматов](docs/SUPPORT.md) · [Сообщить о проблеме](https://github.com/volodyatoxic/videoquick-macos/issues/new).
